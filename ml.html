01 · Decision Trees

1
① Теория

Дерево рекурсивно разбивает выборку на однородные подмножества. Узел — вопрос «признак xj > порога t?», лист — предсказание. Перебираются все признаки и пороги, берётся разбиение с максимальным снижением нечистоты (information gain): Gini для классификации, дисперсия для регрессии. Остановка — pre-pruning (глубина, min_samples) или post-pruning (cost-complexity Rα=R+α|T|). Без этого — переобучение до листьев из 1 объекта.

② Аналогия: фуры, товары и рабочие склада

На склад приезжают фуры с товарами, снаружи никакой информации. Рабочие смотрят внешние параметры (вес, длина, температура кузова) и придумывают правила: «тяжелее 15 тонн — налево». После разделения сравнивают догадки: «слева только холодильники, справа только диваны — вопрос хороший!» В обеих кучах свалка — вопрос плохой. Дерево — цепочка таких вопросов. Переобучение — «номер фуры 347? на полку B12»: на этом складе идеально, на новом — бесполезно.

Порог: x ≤ t → налево, x > t → направо  |  Gini = 1 − ∑i=1C pi2   Qsplit(t) = nLn·IL + nRn·IR   Gain(t) = Iparent − Qsplit(t)
2
③④ Разбор формулы через аналогию
  • t — сам вопрос рабочего: «вес > 15 тонн?». Это конкретное число (порог), по которому фуру отправляют налево или направо. Именно это число двигает ползунок в виджете ниже — при каждом t получается своё разбиение и свой Gain.
  • C — число зон склада; pi — доля фур с товаром i в куче (8 ТВ + 2 джинсы → pэл=0.8).
  • Gini — насколько куча «грязная»: 0 — куча идеально чистая (один товар), чем ближе к 1, тем сильнее всё перемешано.
  • nL,nR — сколько фур ушло налево/направо при пороге t; Qsplit(t) — средняя «грязь» в обеих кучах после этого конкретного вопроса.
  • Gain(t) — насколько вопрос с порогом t навёл порядок: было грязно (Iparent), стало чище (Qsplit) — разница и есть выигрыш. Перебирая t, ищем вопрос с самым большим выигрышем.

import numpy as np
def gini(y):
    _, c = np.unique(y, return_counts=True)
    # ↑ уникальные товары и число фур каждого
    p = c / len(y)                      # доля фур с товаром i (p_i)
    return 1.0 - np.sum(p**2)        # 1-∑p² = шанс ошибиться

def find_best_split(X, y):
    best = (-1.0, None, None); n = len(y); pg = gini(y)
    for f in range(X.shape[1]):
        col = X[:, f]; si = np.argsort(col)
        # ↑ сортируем фуры по признаку
        sc = col[si]
        for t in (sc[:-1]+sc[1:])/2:
            # ↑ пороги между соседними значениями
            lm = col <= t; rm = ~lm     # маски: налево/направо
            nL, nR = lm.sum(), rm.sum()
            if nL==0 or nR==0: continue
            Q = (nL/n)*gini(y[lm]) + (nR/n)*gini(y[rm])
            # ↑ взвешенная нечистота детей
            g = pg - Q
            if g > best[0]: best = (g, f, t)
    return best[1], best[2], best[0]

⑦ Q&A (12)

1. Gini vs Entropy? Дают почти одинаковые сплиты; Gini быстрее (нет log2) — дефолт в CART/sklearn. Entropy — та же идея «нечистоты», но по логарифмической шкале — чуть агрессивнее наказывает смешанные узлы.

2. Почему переобучается? Без ограничений дерево растёт, пока узлы не станут чистыми (в пределе — 1 объект на лист): train-ошибка → 0, но такое дерево запомнило шум конкретной выборки → высокая variance на новых данных.

3. Лечение? Pre/post-pruning, ансамбли.

4. Зачем скейлинг? Не нужен: сплит по порядку значений, не масштабу.

5. Экстраполяция? Нет — константа листа.

6. Граница ступенчатая почему? Сплит параллелен оси.

7. В листе регрессии? Среднее (MSE) / медиана (MAE).

8. MDI bias? Завышена у числовых/многокатегорийных → permutation importance.

9. NaN? sklearn — impute; XGB/CatBoost — default direction.

10. Нестабильность? Сдвиг данных меняет первый сплит → всё дерево другое.

11. XOR выучит? Да (глубина 2); линейная модель — нет.

12. Сложность? O(d·n·log n) с сортировкой.

02 · k-Nearest Neighbors

1
① Теория

«Ленивый» алгоритм: запоминает выборку, новый объект = класс большинства из k ближайших (majority vote; регрессия — среднее/медиана). Метрики: евклид, манхэттен, косинус (разреженные/эмбеддинги). Проблемы: проклятие размерности (расстояния концентрируются) и масштаб признаков → всегда скейлинг + PCA/отбор. Ускорение: KD-tree (d<20), ball tree, FAISS/HNSW, LSH.

② Аналогия: переехал в новый район

Хочешь понять, богатый район. Смотришь на 5 ближайших домов: Tesla+бассейн, BMW, Toyota, Lada+старый забор, Tesla → голоса 3/1/1 → «богатый». Проклятие: оценивай по 1000 признакам (цвет краски в туалете...) — любой сосед уникален, «ближайшие» = случайные. Масштаб: «доход в рублях» [0,10 млн] забьёт «возраст» [0,100] — масштабировать.

d(x,y) = √∑i(xi−yi)²   ŷ = argmaxc ∑j=1k 1[yj=c]   cos = x·y‖x‖·‖y‖

③④ Разбор формулы
  • (xi−yi) — отличие по параметру; (·)² — убрать знак + оштрафовать большие различия; ∑ — суммарное различие; √ — возврат к нормальным единицам.
  • k — сколько домов смотришь (1 = шум, все = «средняя температура»); 1[·] — один голос; argmax — класс с максимумом голосов.
  • cos — сравнение по структуре (пропорции), не по абсолютным значениям.

def knn(X_tr, y_tr, X_te, k=5):
    # трюк: ||a-b||² = ||a||²+||b||²-2ab
    tr = (X_tr**2).sum(1); te = (X_te**2).sum(1)
    D = te[:,None] + tr[None,:] - 2*(X_te @ X_tr.T)
    # ↑ матрица квадратов расстояний через BLAS, (M,N)
    ki = np.argpartition(D, k, 1)[:, :k]
    # ↑ топ-k без полной сортировки, O(N)
    return np.apply_along_axis(lambda r: np.bincount(r).argmax(), 1, y_tr[ki])
    # ↑ majority vote

03 · Support Vector Machines

1
① Теория

Ищет гиперплоскость с максимальным зазором (margin) = 2/‖w‖ → минимизируем ‖w‖². Точки на кромке — support vectors (только они определяют решение). Неразделимо: soft-margin (штраф ξ, параметр C) и kernel trick (неявный подъём в пространство большей размерности через попарные скалярные произведения; Mercer = ядро PSD). SVR: ε-трубка. Обучение QP O(N²–N³) → на больших только линейный SVM/SGD. Скейлинг обязателен.

② Аналогия: самая широкая улица между толпами

Красные и синие на площади; нужна самая широкая улица (обобщение). SV — фанаты у кромки: остальных можно увести — улица не изменится. Soft margin: нескольким фанатам разрешено пересечь кромку; C — строгость полиции. Kernel trick: толпы кольцами — надеваем «очки» (3D), где красные внизу, синие сверху; работаем только с попарными расстояниями в 2D. RBF: точки-«горки»; γ большой = узкие горки = переобучение.

minw,b ½‖w‖² + C∑ξi, s.t. yi(wTxi+b) ≥ 1−ξi   KRBF = e−γ‖x−x′‖²
2
③④ Разбор формулы
  • w — перпендикуляр к улице (длиннее w = уже улица); b — смещение улицы; ½‖w‖² — «узкость», минимизируем = шире.
  • ξi — насколько фанат пересёк кромку; C∑ξ — штраф за нарушителей (C↑ = жёстче = уже улица).
  • KRBF — «близость в очках»: близкие ≈1, далёкие ≈0; γ — радиус влияния.

def svm_sgd(X, y, lam=0.01, epochs=10):
    # y ∈ {+1,-1}; lam — сила L2-регуляризации (аналог 1/C)
    n, w, b, t = len(X), np.zeros(X.shape[1]), 0., 0
    for _ in range(epochs):
        for i in np.random.permutation(n):
            t += 1; lr = 1/(lam*t)
            # ↑ убывающий шаг — классика Pegasos, гарантирует сходимость
            m = y[i]*(X[i]@w + b)
            # ↑ запас: >=1 = на своей стороне с запасом
            if m >= 1:
                w -= lr*lam*w
                # ↑ только регуляризация — тянем w к 0, улица шире
            else:
                w -= lr*(lam*w - y[i]*X[i]); b += lr*y[i]
                # ↑ тянем нарушителя на свою сторону + регуляризация
    return w, b

⑦ Q&A (12)

1. Зачем макс margin? Меньше чувствительность к шуму = лучше обобщение.

2. Support vectors? Точки на кромке; остальные удалимы.

3. C? C↑ меньше ошибок/уже margin (риск переобучения); C↓ шире margin, больше ошибок (риск недообучения). В Pegasos-формулировке роль C играет λ, но обратно: λ↑ ⇔ C↓.

4. Kernel trick? Скалярные произведения в высоком пространстве без координат.

5. RBF переобучение? γ большой — узкие бугры.

6. Зачем скейлинг? Margin и ядро зависят от масштаба.

7. SVM vs логрег? Hinge vs log-loss; SVM разрежен; логрег = вероятности.

8. SVR? ε-трубка; SV = вне трубки.

9. Зачем dual? Только скалярные произведения → ядро.

10. KKT? α>0 только у SV → разреженность.

11. Мерсер? Ядро PSD.

12. 1M строк? LinearSVC/SGD(hinge).

04 · SVR (Support Vector Regression)

1
① Теория

SVR переносит идею SVM на регрессию: вместо разделяющей полосы строится ε-трубка вокруг предсказанной функции. Ошибки внутри трубки (|y−f(x)|≤ε) не штрафуются вообще — модель их «прощает»; ошибки за пределами штрафуются линейно с коэффициентом C. Точки на границе или снаружи трубки становятся support vectors — как и в классификации, только они определяют форму решения, отсюда разреженность. Kernel trick работает так же: RBF/полиномиальное ядро даёт нелинейную SVR без явного перехода в новое пространство признаков.

② Аналогия: дорога с обочиной

Модель прокладывает «дорогу» (предсказанную кривую). Машины (точки данных), едущие в пределах ε от центральной линии, не получают штрафа — это нормальный разброс. Машины, выехавшие за «обочину», получают штраф пропорционально тому, насколько далеко уехали, и строгости патруля C. Только машины у самой границы обочины или за ней (support vectors) реально влияют на то, где проложена дорога — основной поток внутри трубки к форме дороги равнодушен.

min ½‖w‖²+C∑(ξi+ξi*)   s.t. |yi−(wTxi+b)| ≤ ε+ξi   Lε(y,f)=max(0,|y−f|−ε)
2
③④ Разбор формулы через аналогию
  • ε — ширина «бесплатной» полосы вокруг дороги: ошибки меньше ε не считаются вообще.
  • ξi, ξi* — насколько машина выехала за обочину сверху/снизу; всегда ≥0.
  • C — строгость патруля: C↑ → модель сильнее старается держать все точки в трубке (может переобучиться); C↓ → трубке разрешено «прощать» больше нарушителей.
  • Lε — ε-нечувствительная функция потерь: плоская зона (0 штрафа) при |остаток|≤ε, дальше растёт линейно — отсюда и разреженность решения (в отличие от MSE, где штраф есть у КАЖДОЙ точки).

⑦ Q&A (6)

1. Зачем ε? Игнорировать шум внутри допустимого коридора — не подгоняться под каждую мелочь.

2. Кто становится SV? Точки на границе или за пределами ε-трубки.

3. Роль C? Как и в классификации: C↑ — жёстче подгонка, меньше сглаживания.

4. ε=0 что будет? Модель штрафует любое отклонение — трубка вырождается, теряется разреженность.

5. Ядра работают? Да, тот же kernel trick, что и в SVM — RBF SVR даёт нелинейную кривую.

6. Когда предпочесть GBM? На больших данных или без нужды в гладкой функции — GBM быстрее и часто точнее.

05 · AdaBoost

1
① Теория

AdaBoost (Adaptive Boosting) — исторически первый практичный бустинг. Идея: обучаем слабые классификаторы (обычно stumps — деревья глубины 1) последовательно на ОДНИХ И ТЕХ ЖЕ данных, но с меняющимися весами объектов — после каждого раунда вес неверно классифицированных точек растёт, вес верно классифицированных падает, так что следующий слабый классификатор вынужден сосредоточиться на «трудных» примерах. Финальный прогноз — взвешенное голосование всех слабых классификаторов, вес голоса αm зависит от того, насколько точен был классификатор m. Позже показали (Hastie/Tibshirani/Friedman): AdaBoost — частный случай forward stagewise аддитивного моделирования, минимизирующего экспоненциальную функцию потерь — то есть AdaBoost и Gradient Boosting (06) — родственники, только с разной функцией потерь.

② Аналогия: репетиторы и трудные темы

Класс готовится к экзамену через серию репетиторов. После пробного теста репетитор №2 получает список учеников, которые чаще всего ошибались (их «вес внимания» вырос), и фокусируется именно на них — а не повторяет то, что все уже знают. На финальном экзамене голос каждого репетитора учитывается с весом, зависящим от того, насколько хорошо в среднем (с учётом текущих весов учеников) он предсказывал ошибки — репетитор, чьи советы не лучше подбрасывания монеты, вообще не получает права голоса.

εm = ∑wi·1[yi≠hm(xi)]∑wi   αm = ½ln1−εmεm   wi ← wi·e−αmyihm(xi)   H(x)=sign(∑αmhm(x))

③④ Разбор формулы через аналогию
  • εm — доля учеников (взвешенная по вниманию), которых репетитор m в среднем «завалил» — его взвешенная ошибка.
  • αm — вес голоса репетитора на финале: если εm мало (репетитор хорош) — αm большое и положительное; если εm=0.5 (как монетка) — αm=0, голоса нет; если εm>0.5 (хуже монетки) — αm<0, голос переворачивают (значит репетитор системно учит наоборот).
  • wi←wi·e±α — если ученика i угадали верно (yihm(xi)>0), его вес внимания падает (умножили на e−α<1); если ошиблись — вес растёт (умножили на e+α>1) — и растёт тем сильнее, чем увереннее (весомее) был этот репетитор.

⑦ Q&A (8)

1. Что учится на каждом раунде? Слабый классификатор (обычно stump) на текущих весах объектов.

2. Как выбирается αm? По взвешенной ошибке текущего классификатора — чем она ниже, тем больше вес голоса.

3. Что если εm=0.5? αm=0 — классификатор не лучше монетки, вклада в ансамбль нет.

4. Что если εm>0.5? αm<0 — голос переворачивают (модель выучила анти-паттерн).

5. Чувствительность к выбросам? Высокая — экспоненциальный рост весов на систематически неверно классифицированных точках.

6. Связь с Gradient Boosting? AdaBoost = forward stagewise минимизация экспоненциального лосса — частный случай GBM.

7. Почему базовые модели такие слабые (stumps)? Специально: сильная база быстро выучит весь train и бустить будет нечего — слабая оставляет ансамблю работу.

8. Переобучение? На практике реже, чем можно ожидать (теория margin), но реально при сильно зашумлённых метках.

06 · Gradient Boosting

1
① Теория

Ансамбль деревьев последовательно: каждое исправляет ошибки предыдущих. F = F₀+ηh₁+…; на шаге считаем антиградиент лосса ri=−∂L/∂F и фитим дерево на ri (регрессия!), F←F+ηh. Это градиентный спуск в пространстве функций. MSE: r=y−F; logloss: r=y−p; quantile: pinball. Регуляризация: lr (малый шаг = больше деревьев = обобщение), subsample/colsample, depth, early stopping.

② Аналогия: скульптор высечивает Давида

F₀ — грубая глыба (среднее). Дерево 1: где форма сильнее всего отличается (справа много мрамора) — высечивает торс. Дерево 2: новый остаток — руки толстые — поправляет. lr — сила удара: лёгкие касания = плавная статуя, мощные = отбил лишнее. Subsample — смотреть с другого ракурса. Early stopping — отходить и смотреть издалека: «жюри» не хвалит → стоп.

Fm = Fm−1 + η·hm,   hm = argminh∑(h(xi)−ri)²,   ri = −∂L(yi,F)∂F
2
③④ Разбор формулы
  • Fm — статуя после m ударов; η — сила удара; hm — сам удар («сколько мм срезать»).
  • ri — «где не доделано»: для MSE = y−F (плюс = не хватает мрамора).
  • argmin∑(h−r)² — дерево учится повторить идеальный остаток; −∂L/∂F — общий случай для любого лосса.

from sklearn.tree import DecisionTreeRegressor
def gbm(X, y, n=100, lr=.1, d=3):
    F = np.full(len(y), y.mean())
    # ↑ F0 = среднее (грубая глыба)
    trees=[]
    for m in range(n):
        r = y - F
        # ↑ антиградиент MSE = остатки
        t = DecisionTreeRegressor(max_depth=d).fit(X, r)
        # ↑ дерево предсказывает остатки
        F += lr*t.predict(X)
        # ↑ срез с коэффициентом η
        trees.append(t)
    return trees

07 · Linear Regression / OLS

1
① Теория

MSE → нормальные уравнения; геометрически ŷ — это ортогональная проекция вектора y на подпространство, натянутое на столбцы X (поэтому вектор остатков y−ŷ перпендикулярен каждому признаку — это и есть суть «нормальных» уравнений). Теорема Гаусса–Маркова: среди всех линейных несмещённых оценок OLS имеет наименьшую дисперсию (BLUE — Best Linear Unbiased Estimator), не требуя нормальности шума; при дополнительном условии, что шум нормальный, OLS-оценка ещё и совпадает с оценкой максимального правдоподобия (MLE). Диагностика: residual plot (воронка = гетероскедастичность, U-форма = нелинейность), QQ-plot (нормальность), Cook's distance (влиятельные выбросы), VIF>5–10 (мультиколлинеарность), критерий Дарбина–Уотсона DW≈2 (отсутствие автокорреляции остатков).

② Аналогия: тень предмета на стене

Представь y — точку в пространстве, а все возможные комбинации признаков Xθ — плоскую стену (подпространство). OLS ищет точку на стене, ближайшую к y — это и есть «тень» y при перпендикулярном освещении (проекция). Расстояние от y до тени — необъяснённый остаток; он обязан быть перпендикулярен стене, иначе тень можно было бы подвинуть и уменьшить расстояние. Мультиколлинеарность — это когда два направления на стене почти совпадают (два прожектора светят почти под одним углом): найти тень можно, но разложить её вклад между двумя направлениями — нет, отсюда огромные и нестабильные коэффициенты θ.

08 · Ridge / Lasso / ElasticNet

1
① Теория

Ridge сжимает все веса понемногу и никогда не обнуляет — штраф ‖θ‖² (сумма квадратов) гладкий везде, поэтому у минимума нет причины «зацепиться» ровно за 0. Lasso использует штраф ‖θ‖₁ (сумма модулей) — у него есть излом ровно в нуле, и именно об этот излом коэффициенты «спотыкаются» и обнуляются: soft-thresholding S(z,λ)=sign(z)(|z|−λ)₊ буквально даёт 0 при |z|≤λ. ElasticNet = смесь обоих штрафов — сжимает как Ridge и обнуляет как Lasso, при этом не роняет случайно одного из двух похожих (коррелированных) признаков, как это может сделать чистый Lasso. Скейлить обязательно (иначе штраф несправедливо давит на признаки с маленьким размахом); λ подбирается по CV.

② Аналогия: сколько багажа разрешено взять

Представь: у тебя есть «идеальный» набор чемоданов (это OLS-решение без штрафа) — но авиакомпания вводит ограничение на общий багаж. Правило Ridge — «сумма квадратов веса чемоданов ≤ лимит»: это круглая зона допустимого багажа, поэтому обрезание идёт равномерно со всех сторон, ни один чемодан не выбрасывается целиком. Правило Lasso — «сумма весов чемоданов ≤ лимит» (без квадрата): зона допустимого багажа — ромб с острыми углами, и решение почти всегда «прилипает» именно к углу ромба, где один из чемоданов весит ровно 0 — то есть выброшен целиком. Чем строже лимит (больше λ), тем меньше зона — и тем сильнее urезаны чемоданы.

Ridge: θ1²+θ2² ≤ t  (круг)  |  Lasso: |θ1|+|θ2| ≤ t  (ромб)  |  S(z,λ)=sign(z)(|z|−λ)₊
2
③④ Разбор формулы через аналогию
  • t (лимит багажа) — уменьшается, когда λ растёт: чем сильнее штраф, тем теснее зона допустимых θ.
  • Круг (Ridge) — гладкая граница без углов: решение может остановиться в любой точке окружности, обе координаты остаются ненулевыми.
  • Ромб (Lasso) — острые углы лежат ровно на осях (там, где одна координата = 0); эллипс ошибки почти всегда касается ромба именно в углу — отсюда обнуление слабого признака.
  • В виджете ниже: «слабый» признак (тонкая, малозначимая ось) у Lasso обнуляется уже при небольшом λ, а у Ridge — только приближается к нулю, но никогда его не касается.

def cd_step(Xs, y, theta, j, lam):
    resid = y - Xs @ theta + Xs[:,j]*theta[j]
    # ↑ остаток БЕЗ вклада признака j (временно "выключили" его)

    # ↑ soft-threshold: если |rho|<=lam — признак зануляется
    return theta

09 · Polynomial Regression

1
① Теория

Полиномиальная регрессия расширяет признаки (x, x², x³, …, попарные произведения xixj), а дальше применяет ту же самую OLS (07) поверх нового набора признаков. Модель остаётся линейной по параметрам θ — нелинейность спрятана только в преобразовании входа φ(x), поэтому вся математика нормальных уравнений работает без изменений. Расплата: высокая степень d даёт дикие колебания между точками (переобучение) и катастрофическую числовую нестабильность (x10 при x=100 — огромное число, cond(XTX) взлетает). Поэтому на практике почти всегда связка PolynomialFeatures + StandardScaler + Ridge — регуляризация укрощает разболтанные коэффициенты у высоких степеней.

② Аналогия: тот же станок, но с большим набором деталей

OLS — это станок, который собирает прогноз как линейную комбинацию входных деталей. Обычная линейная регрессия даёт станку только «прямые палки» (x). Полиномиальная регрессия добавляет в ящик деталей «изогнутые дуги» (x², x³…) — но станок по-прежнему просто взвешенно складывает детали, механика сборки не поменялась. Дать станку слишком много изогнутых деталей высокой степени — он начнёт вырисовывать замысловатую загогулину, идеально проходящую через каждую обучающую точку (включая шум), но абсолютно бессмысленную между ними и за краями данных.

ŷ = θ0+θ1x+θ2x²+…+θdxd = θTφ(x),   φ(x)=[1,x,x²,…,xd]
2
③④ Разбор формулы через аналогию
  • φ(x) — набор деталей, поданных в станок OLS; сам станок (нормальные уравнения) не знает и не заботится, что x² — это «x в квадрате», для него это просто ещё одна колонка признаков.
  • d — степень: маленькое d = станок не может изогнуть линию (недообучение, пропускает кривизну); большое d = станок вычерчивает загогулину через каждую точку (переобучение), а вне диапазона данных xd уходит в ±∞ — экстраполяция катастрофична.
  • θ — по-прежнему обычные коэффициенты OLS, только теперь при x² и x³ они могут быть огромными и противоположных знаков (взаимно компенсирующими) — признак нестабильности, лечится Ridge.

⑦ Q&A (6)

1. Всё ещё линейная модель? Да — линейна по параметрам θ, нелинейна только по исходному x.

2. Переобучение? Высокая степень = дикие колебания между точками — учебный пример bias-variance trade-off.

3. Экстраполяция? Катастрофична: полином улетает в ±∞ за пределами диапазона обучающих x.

16 · Hierarchical Clustering

1
① Теория

Агломеративная (снизу вверх, самый частый вариант) иерархическая кластеризация: каждая точка начинает как отдельный кластер, на каждом шаге сливаются два САМЫХ БЛИЗКИХ кластера, пока не останется один — история слияний записывается как дендрограмма. «Близость» между кластерами (не точками!) задаётся linkage: single (расстояние между ближайшими точками — даёт длинные «цепочки»), complete (между самыми далёкими — компактные, примерно равные по размеру кластеры), average, Ward (слияние, минимально увеличивающее внутрикластерную дисперсию — самый популярный дефолт, даёт сбалансированные «округлые» кластеры). K не нужно знать заранее — дендрограмму строят целиком, а число кластеров выбирают ПОСЛЕ, разрезая дерево на нужной высоте. Минус: O(n²) память на матрицу попарных расстояний, O(n²log n) и хуже по времени — на больших n (десятки тысяч+) непрактично.

② Аналогия: история поглощений компаний

Дендрограмма — это восстановленная задним числом история слияний и поглощений: сначала существуют только маленькие независимые компании (отдельные точки); на каждом шаге сливаются два САМЫХ близких по духу игрока в один; так продолжается, пока рынок не схлопнется в одну гигантскую корпорацию. «Разрезать дерево на высоте Y» значит «остановить историю поглощений в момент Y и посмотреть, сколько независимых компаний ещё осталось» — то есть выбрать число кластеров постфактум, глядя на дерево, а не гадать заранее.

Ward: ΔSSE = nAnBnA+nB·‖μA−μB‖²
2
③④ Разбор формулы через аналогию
  • μA, μB — «штаб-квартиры» (центроиды) двух компаний-кандидатов на слияние; чем они дальше друг от друга, тем более разные компании.
  • nA, nB — размеры компаний; вес nAnB/(nA+nB) означает, что слияние двух маленьких компаний «стоит дёшево» (мало прибавляет разброса), а двух больших и далёких — «дорого».
  • ΔSSE — насколько вырастет суммарный внутрикластерный разброс после слияния; Ward-алгоритм на каждом шаге выбирает пару с МИНИМАЛЬНЫМ ΔSSE — отсюда компактные, сбалансированные кластеры, а не длинные цепочки, как у single linkage.
⑤ SCIPY

⑥ Почему не легаси
single linkage вслепую
На данных с «мостиком» из шумных точек между двумя плотными облаками single linkage склеит их в одну длинную цепь — классический провал.
Ward по умолчанию
Даёт компактные сбалансированные кластеры в большинстве практических случаев — разумный дефолт, если нет причин выбрать другой linkage.
hierarchical на 100k+ строк
O(n²) память на матрицу расстояний — не влезет; переходить на MiniBatch k-means или сэмплировать перед кластеризацией.
⑦ Q&A (6)

1. Single vs Ward? Single цепляет длинные «цепочки» через шум; Ward даёт компактные сбалансированные кластеры.

2. Как выбрать число кластеров? Не задаётся заранее — по высоте среза дендрограммы (например, самый длинный вертикальный «разрыв» между слияниями).

3. Сложность? O(n²) память, O(n²log n) и хуже по времени — не для больших n.

4. Детерминированность? Да, в отличие от k-means — нет случайной инициализации.

5. Divisive vs agglomerative? Agglomerative — снизу вверх (стандарт); divisive — сверху вниз, реже и дороже.

6. Когда предпочесть k-means? Когда данных много и заранее нужен один конкретный k; hierarchical — для разведочного анализа и малых/средних n.

17 · Gaussian Mixture Models

1
① Теория

Gaussian Mixture Model — вероятностная, мягкая кластеризация: данные считаются порождёнными смесью K гауссиан, у каждой свои центр μk, ковариация Σk и вес πk (насколько кластер «популярен»). Обучение через EM-алгоритм: E-шаг считает «ответственность» γik — вероятность, что точка i принадлежит кластеру k при текущих параметрах (мягкое, не жёсткое присвоение, как в k-means); M-шаг пересчитывает μk,Σk,πk как взвешенные (по ответственностям) средние. Повторяем до сходимости правдоподобия. В отличие от k-means (неявно требует сферических кластеров одинакового размера), полная ковариация Σk позволяет кластерам быть эллипсами произвольной ориентации и размера. Число кластеров K выбирают по BIC/AIC (штраф за число параметров). reg_covar — маленькая добавка к диагонали Σk, спасающая от вырождения ковариации при малом числе точек в кластере или высокой размерности.

② Аналогия: клубы по интересам с нечёткими границами

K-means распределяет каждого студента ровно в один кружок — жёсткое членство. GMM говорит иначе: «этот студент на 70% из кружка робототехники и на 30% из шахматного клуба» — вероятностное, мягкое членство. Более того, у каждого кружка своя «форма личности»: шахматный клуб — вытянутое узкое сообщество (все примерно одинаково интровертны), а кружок робототехники — широкий и разнородный (эллипс другой формы и ориентации), в отличие от k-means, где все кружки насильно одинаково круглые.

p(x)=∑kπkN(x|μk,Σk)   γik = πkN(xi|μk,Σk)∑jπjN(xi|μj,Σj)
2
③④ Разбор формулы через аналогию
  • N(x|μk,Σk) — насколько правдоподобно, что студент x из кружка k, судя по «форме» и центру этого кружка.
  • πk — насколько кружок k вообще популярен в целом (априорная доля) — до того, как мы посмотрели на конкретного студента.
  • γik — формула Байеса: превращает «насколько правдоподобен x под каждым кружком» в «раз уж мы видим именно этого студента, какова вероятность, что он из кружка k» — числитель для своего k, знаменатель нормирует по всем K кружкам, чтобы сумма ответственностей по k была равна 1.

⑥ Почему не легаси
GMM вместо k-means
K-means — частный случай GMM с фиксированной равной сферической ковариацией и жёстким присвоением; когда кластеры вытянуты или разного размера — k-means физически не может это представить, GMM может.
full covariance в высокой размерности
O(d²) параметров на кластер — при малом n на кластер или большом d ковариация легко вырождается; спасает reg_covar или covariance_type='diag'.
случайная инициализация без k-means++
EM может застрять в плохом локальном оптимуме; sklearn по умолчанию стартует с k-means-инициализации не просто так.
⑦ Q&A (6)

1. GMM vs k-means? Мягкие вероятностные метки + эллипсоидные (не только сферические) кластеры произвольного размера.

2. Шаги EM? E — посчитать ответственности при текущих параметрах; M — пересчитать параметры при текущих ответственностях; повторять до сходимости.

3. Зачем reg_covar? Без него Σk может выродиться (стать сингулярной) при малом числе точек в кластере или высокой размерности.

4. Как выбрать K? BIC/AIC — штрафуют за число параметров, ищут баланс качества и сложности модели.

5. Зачем k-means-инициализация? Без неё EM чаще застревает в плохом локальном максимуме правдоподобия.

6. GMM — обобщение чего? K-means — её частный случай при равной сферической ковариации и argmax вместо мягких весов.

18 · Mean Shift

1
① Теория

Mean Shift — кластеризация через поиск мод плотности, без заранее заданного K. Для каждой точки итеративно сдвигаем её к взвешенному среднему соседей в радиусе bandwidth h (вес по ядру, обычно гауссову) — это буквально подъём по оценке плотности (KDE) вверх, пока точка не сойдётся к локальному максимуму («моде»). Все точки, сошедшиеся к одной моде, образуют один кластер. Число кластеров возникает из данных само — реальный гиперпараметр здесь h (аналог eps у DBSCAN): маленький h — много мелких мод (много кластеров), большой h — всё сглаживается в один общий холм. Минус: наивная реализация — O(n²) на итерацию, плохо масштабируется; выбор h в высокой размерности неочевиден.

② Аналогия: шарик, катящийся в гору по ландшафту плотности

Представь ландшафт из холмов, где высота в точке — это насколько «густо» там данных. В каждую точку данных кладём шарик и отпускаем его «катиться в гору» — он движется в сторону, куда локально плотнее всего соседей. Все шарики, скатившиеся на одну и ту же вершину, — один кластер. Bandwidth h — это «дальнозоркость» шарика: с маленьким h он видит только ближайшую кочку и застревает на мелких локальных пиках (много кластеров); с большим h он видит весь ландшафт целиком как один пологий холм (один кластер).

m(x) = ∑ixiK(‖xi−x‖/h)∑iK(‖xi−x‖/h) − x   x ← x+m(x)
2
③④ Разбор формулы через аналогию
  • K(·) — ядро, взвешивающее соседей: близкие соседи весят больше, дальние — почти 0 (за пределами дальнозоркости h — вообще не видны).
  • h — радиус «дальнозоркости» шарика: определяет, какие соседи вообще учитываются при выборе направления «в гору».
  • m(x) — вектор сдвига: разница между «где сейчас взвешенный центр тяжести соседей» и «где сейчас шарик» — это и есть направление подъёма по плотности; повторное добавление m(x) к x — и есть подъём в гору шаг за шагом, пока m(x) не станет ≈0 (вершина найдена).

Как и DBSCAN — число кластеров определяется данными и h, а не задаётся руками заранее.

Обычно быстрее, параметр eps интерпретируется проще, есть явное понятие «шум» — на практике предпочитают DBSCAN, если форма кластеров не требует именно поиска мод плотности.
⑦ Q&A (6)

1. Зачем не нужен K? Число кластеров = число найденных мод плотности, определяется данными и h.

2. Главный гиперпараметр? Bandwidth h: маленький — много мелких кластеров, большой — один общий.

3. Сложность? O(n²) на итерацию в наивной реализации — плохо масштабируется на большие n.

4. На что похож алгоритм? На градиентный подъём по оценке плотности (KDE) к ближайшему локальному максимуму.

5. Mean Shift vs DBSCAN? Оба не требуют K; DBSCAN обычно быстрее и явно выделяет шум, Mean Shift ищет моды плотности.

6. Форма кластеров? Может находить кластеры произвольной формы, но чувствителен к выбору h.

② Аналогия

Свёртка — трафарет, который двигают по картинке клетка за клеткой: под трафаретом лежат числа картинки, они умножаются на числа трафарета и складываются в одно число результата.
